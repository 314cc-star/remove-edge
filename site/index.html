How to remove Microsoft Edge

  1. Download RemoveEdge-x64.exe. Most PCs need the x64 version. Use ARM64 for Snapdragon or Surface Pro X devices.
  2. Run it by double-clicking the file. If SmartScreen appears, click More info → Run anyway.
  3. Allow admin access by clicking Yes in the Windows (UAC) prompt.
  4. Confirm by typing Y and pressing Enter, then wait for [OK].
  5. Restart your PC to finish.

What RemoveEdge does

Closes Edge

Stops msedge.exe and Edge Update processes so files aren't locked.

Unlocks uninstall

Sets EdgeUpdateDev\AllowUninstall so Edge's own setup will uninstall outside the EEA.

Runs the official uninstaller

Calls Edge's own setup.exe --uninstall --force-uninstall for both the system and per-user installs.

Blocks reinstall

Sets the DoNotUpdateToEdgeWithChromium policy and removes leftover shortcuts.

Not touched: Microsoft Edge WebView2 Runtime. Apps like Teams, Office and many games need it to work.

Prefer to do it manually?

Open Terminal (Admin) and run the following. Replace the version folder with the one under C:\Program Files (x86)\Microsoft\Edge\Application\.

reg add "HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdateDev" /v AllowUninstall /t REG_DWORD /d 1 /f
cd "C:\Program Files (x86)\Microsoft\Edge\Application\<version>\Installer"
.\setup.exe --uninstall --system-level --verbose-logging --force-uninstall

FAQ

Why can't I uninstall Microsoft Edge?

Microsoft treats Edge as a Windows system component. Outside the European Economic Area (EEA) the Uninstall button in Settings is greyed out, so Edge can't be removed the normal way.

Is it safe to remove Microsoft Edge?

For most people, yes. RemoveEdge keeps WebView2 Runtime, which many apps need. A few Windows features such as Widgets may open links in your default browser instead, or stop working. Set another browser as your default before you run it.

Will Windows Update reinstall Edge?

RemoveEdge sets a policy that blocks reinstalling, but some major Windows feature updates may still bring Edge back. If that happens, just run RemoveEdge again.

It says [FAILED]. What now?

Some Edge versions block uninstalling. Open C:\Windows\Temp\msedge_installer.log and open an issue with the last lines of the log.

How do I get Edge back?

Download the official installer from microsoft.com/edge and run it.

Why does SmartScreen or my antivirus warn me?

RemoveEdge is new and unsigned, and it changes registry settings, so security tools don't recognise it yet. You can read every line of the source code on GitHub before running it.
